# How do I start a session memory folder?

1. Copy this folder to `AI/memory/<YYYY-MM-DD>-<slug>/`.
2. In the copy, replace the placeholders in `index.md` and `state.md`.
3. Fix the wikilinks in the copy so they use the new folder path.
4. Add the session line to [[AI/memory/memory]].
5. Create `decisions.md` and `log-<writer>.md` files from the templates in [[AI/memory/session-format]].

Check: the link check in [[AI/memory/compaction]] prints `0 broken`.
