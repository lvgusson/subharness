# Design patterns

This folder is empty on purpose. Add one note for each pattern your project uses. A pattern note says where the pattern lives and how to extend it. Use a pattern for the behavior it gives, not for style.

## Template

```markdown
---
name: <pattern-name>
description: <Pattern> in use, where it lives, and how to extend it.
type: reference
area: patterns
---

# <Pattern name>

| Pattern  | Where              | Use it to          |
| -------- | ------------------ | ------------------ |
| <name>   | `<path/to/file>`   | <the behavior it gives> |

Extend it by adding an implementation, not by editing callers.
```
